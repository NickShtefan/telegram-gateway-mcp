# Открытые вопросы

Решения здесь принимает владелец. Агент может предложить вариант с доводами, но не выбирает сам.

## Решено

- **От чьего имени пишет агент** (2026-10-01): от подключённого аккаунта. Это отдельный аккаунт агента или личный аккаунт владельца, если он сам его подключил. В канале, где аккаунт админ, можно писать от имени канала (`send_as`). См. [decisions.md](decisions.md), решение 9.
- **Где живёт проект** (2026-10-01): локальная папка `~/Projects/CODE/Chanel/tg-mcp`, приватный репозиторий `telegram-gateway-mcp`. См. решения 11 и 14.
- **Номер и учётные данные приложения** (2026-10-01): `API_ID`, `API_HASH` и номер берутся из `.env` channel-scope на лабораторной машине. Вход в шлюз отдельный, сессия channel-scope не используется. Установщик забирает значения сам (`TG_MCP_API_ENV`), см. [deploy.md](deploy.md).
- **Где работает демон** (2026-10-01): на лабораторной машине `macbook-pro-lab.local`, рядом с Claude Code, Codex, OpenCode и Hermes. См. решение 12.
- **Как устроен бот-мост** (2026-10-01, по наблюдению на лабораторной машине): Claude Code подключён к Telegram официальным плагином channels (Bot API), у Hermes свой Telegram-шлюз. Токены обоих ботов заняты своими получателями обновлений. См. [findings.md](findings.md).
- **Способ переписки в кейсе 4** (2026-10-01): пишет подключённый аккаунт. Вариант через Business-бота (решение 13) снят вместе с ботом согласований, см. решение 23.
- **Имя** (2026-10-01): приватный репозиторий `telegram-gateway-mcp`, в npm пока не публикуем. См. решение 14.
- **Какие каналы мониторить** (2026-10-01): любые; список наблюдаемых чатов агент ведёт сам. См. решение 15.
- **Кто пользуется шлюзом** (2026-10-01): владелец и жена владельца, у каждого свои аккаунты Telegram, есть общие. См. решение 16.
- **Под каким пользователем macOS работает демон** (2026-10-01): под отдельным; сессии и ключ агентам недоступны. См. решение 17.
- **Общие аккаунты** (2026-10-01): подтверждает тот, кто запустил; посторонние сообщения видят все пользователи аккаунта; правила и поручения видны всем, меняет автор; один ответ на пост с аккаунта. См. решение 18.
- **Драйвер SQLite и режим работы агента** (2026-10-01): `node:sqlite`; коммиты и пуш в `main` по шагам; фазы 0-3 без остановки. См. решение 19.
- **Бот для согласований** (2026-10-01): не нужен. Запись подтверждается в разговоре со своим агентом: предпросмотр, затем `tg_confirm`. См. решение 23.
- **Шлюз как агент или как инструмент** (2026-10-01): только инструмент. Runner, правила, поручения, наблюдение, входящие и разбор цен убраны. См. решение 25.

## Ждёт подтверждения владельца

Решения 20, 22 и 24 в [decisions.md](decisions.md) агент принял сам по ходу автономной работы (решение 19). Они помечены «предложено» и действуют, пока владелец не скажет иначе. Самые заметные:

- **Глобальный поиск не ищет по личным перепискам**, даже открытым владельцем (решение 22).
- **Установка только из копии установщика под root и по sha коммита** (решение 22).
- **Индекс наполняется только по вызову и хранит тексты чатов в базе шлюза** (решение 24).
