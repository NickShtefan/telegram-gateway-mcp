# Открытые вопросы

Решения здесь принимает владелец. Агент может предложить вариант с доводами, но не выбирает сам. Уже принятое записано в [decisions.md](decisions.md).

## Ждёт подтверждения владельца

Решения 20, 22 и 24 агент принял сам по ходу работы. Они помечены «предложено» и действуют, пока владелец не скажет иначе. Самые заметные:

- **Установка только из копии установщика под root и по sha коммита** (решение 22).
- **Индекс наполняется только по вызову и хранит тексты чатов в базе шлюза** (решение 24).

## Можно решить позже

1. **Общий пакет с channel-scope.** Приёмы перенесены в tg-mcp копией. Сделать ли общий пакет ядра, чтобы channel-scope и tg-mcp не расходились?
2. **Premium у аккаунта агента.** Полнотекстовый поиск по всем публичным постам Telegram доступен только с Premium и дневной квотой. Нужен ли он?
3. **Публикация.** Публиковать ли в npm и под каким именем. `tg-mcp` в npm занят чужим пакетом.
4. **Скрытые ссылки в постах.** Шлюз собирает ссылки, спрятанные под текстом поста (слово «тут» со ссылкой), но в ответах инструментов их не показывает: агент видит только текст. Показывать ли их в режиме `full`?
