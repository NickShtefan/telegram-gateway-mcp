# tg-mcp

Telegram MCP-шлюз. Один долгоживущий демон держит сессию Telegram-аккаунта и отдаёт её агентам (Claude Code, Codex, OpenCode, Hermes и любым MCP-клиентам) как набор инструментов: поиск по каналам и чатам, чтение истории и комментариев, скачивание картинок, мониторинг с ответами и переписка с людьми по поручению.

**Статус:** фазы 0 и 1 написаны и покрыты тестами (ядро, вход, чтение, поиск, комментарии, выгрузка, медиа, HTTP-демон, stdio-прокладка). Живая проверка на Telegram ждёт тестового номера. Текущее состояние: [docs/plan.md](docs/plan.md).

**Репозиторий:** приватный `telegram-gateway-mcp`, в npm не публикуется. Демон работает на лабораторной машине `macbook-pro-lab.local` рядом с агентами. Пользуются двое, владелец и жена владельца: у каждого свои аккаунты Telegram, есть общие.

**Интерактивная схема:** https://claude.ai/artifact/5ncPNinpdXDZR3RGsQJ6y3 (приватная, открывается только владельцу). Локальная копия: [docs/architecture.html](docs/architecture.html).

## Что должен уметь

| Кейс | Пример просьбы к агенту | Тип |
|---|---|---|
| 1. Цены в барахолке | «Зайди в чат барахолки, найди объявления на тему X и дай аналитику по ценам» | разовый запрос |
| 2. Сводка по каналу | «Зайди на канал и расскажи, о чём там говорят» | разовый запрос |
| 3. Мониторинг и ответы | «Следи за каналом и отвечай на новые посты в комментариях» | постоянная задача (правило) |
| 4. Переписка и договорённость | «Напиши такому-то аккаунту и договорись о том-то» | постоянная задача (поручение) |
| Во всех кейсах | скачивать изображения для последующего анализа | |

Подробно: [docs/use-cases.md](docs/use-cases.md).

## Быстрый старт для разработки

```bash
npm ci && npm run build && npm test
```

```bash
node dist/cli/index.js help
```

Состояние лежит в `~/.tg-mcp` (или в `TG_MCP_HOME`). Учётные данные приложения Telegram кладутся в `<папка>/.env` как `TG_API_ID` и `TG_API_HASH`.

## Соседние репозитории

Все лежат рядом, в `~/Projects/CODE/Chanel/`:

- **channel-scope** (ветка `feat/mcp-server`): исследование каналов. Отсюда берём мультиаккаунтный менеджер клиентов, лимитер с FLOOD_WAIT, поиск, рекомендации, медиа, аналитику. Там же существующий MCP для CRM-пайплайна: он остаётся отдельным.
- **helper** (ветка `main`): архив канала @stonksnws. Отсюда берём защиту от зависаний GramJS, одну полосу MTProto-вызовов, чтение комментариев из группы обсуждений, слежение за постами, авто-реакции.
- **canary**, **tgbot**: ежедневная сводка по крипте через Bot API. Отсюда только пример отправки с inline-кнопками.
- **blog**, **helper_old**: к проекту не относятся.
